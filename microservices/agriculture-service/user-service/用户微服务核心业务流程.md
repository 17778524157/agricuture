# 用户微服务核心业务流程

## 1. 用户登录流程

### 1.1 用户名密码登录流程

```
┌─────────────┐
│ 用户输入    │
│ 用户名+密码 │
└──────┬──────┘
       │
       ▼
┌─────────────────────────┐
│ 检查登录权限            │
│ - 账户是否锁定          │
│ - 登录失败次数          │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 查询用户信息            │
│ - 根据用户名查询        │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 验证角色                │
│ - 检查角色是否匹配      │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 验证密码                │
│ - MD5加密后比对         │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 生成JWT Token           │
│ - userId, username, role│
│ - 有效期24小时          │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 获取角色菜单            │
│ - 根据角色查询菜单权限  │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 处理登录成功            │
│ - 保存Token到Redis      │
│ - 用户上线              │
│ - 清除失败次数          │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 返回登录响应            │
│ - Token                 │
│ - 用户信息              │
│ - 菜单列表              │
└─────────────────────────┘
```

```
┌─────────────────────────┐
│ 用户填写注册信息        │

│ - 验证码                │

└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 验证请求参数            │
│ - 密码一致性            │
│ - 手机号格式            │
│ - 邮箱格式              │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 检查用户名唯一性        │
│ - 查询数据库            │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 检查手机号唯一性        │
│ - 查询数据库            │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 检查邮箱唯一性          │
│ - 查询数据库(如果有)    │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 验证手机验证码          │
│ - 从Redis获取验证码     │
│ - 比对输入的验证码      │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 创建用户对象            │
│ - 密码MD5加密           │
│ - 设置默认角色          │

└──────┬──────────────────┘
       │
       ▼

│ 保存到数据库            │

       │
       ▼
┌─────────────────────────┐
│ 删除已使用的验证码      │

└──────┬──────────────────┘

       ▼
┌─────────────────────────┐
│ 返回注册响应            │
│ - 用户ID                │
│ - 用户名                │
│ - 注册成功消息          │

```

## 3. 登录安全机制

### 3.1 防暴力破解流程

```
┌─────────────────────────┐
│ 登录请求                │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 检查账户锁定状态        │
│ Redis Key:              │
│ login:lock:{username}   │
└──────┬──────────────────┘
       │ 已锁定
       ├──────────────────────┐
       │                      │
       │ 未锁定               ▼
       │              ┌────────────────┐
       │              │ 返回锁定提示    │
       │              │ "账户已锁定，    │
       │              │  请30分钟后重试" │
       │              └────────────────┘
       ▼
┌─────────────────────────┐
│ 检查登录失败次数        │
│ Redis Key:              │
│ login:fail:{username}   │
└──────┬──────────────────┘
       │
       │ 失败次数 >= 5
       ├──────────────────────┐
       │                      │
       │ 失败次数 < 5          ▼
       │              ┌────────────────┐
       │              │ 锁定账户30分钟  │
       │              │ 设置锁定标识    │
       │              └────────────────┘
       ▼
┌─────────────────────────┐
│ 继续登录验证            │
└──────┬──────────────────┘
       │
       │ 登录成功
       ├──────────────────────┐
       │                      │
       │ 登录失败              ▼
       │              ┌────────────────┐
       │              │ 清除失败次数    │
       │              │ 清除锁定标识    │
       │              └────────────────┘
       ▼
┌─────────────────────────┐
│ 增加失败次数            │
│ 失败次数 +1             │
│ TTL: 15分钟             │
└─────────────────────────┘
```

### 3.2 Token管理流程

```
┌─────────────────────────┐
│ 用户登录成功            │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 生成JWT Token           │
│ - userId                │
│ - username              │
│ - role                  │
│ - expiresAt (24h)       │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 保存Token到Redis        │
│ Key: login:token:{token}│
│ TTL: 24小时             │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 返回Token给客户端       │
└─────────────────────────┘

用户请求:
┌─────────────────────────┐
│ 客户端携带Token请求     │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 验证Token               │
│ 1. 检查Token黑名单      │
│ 2. 验证Token签名        │
│ 3. 检查Token过期        │
└──────┬──────────────────┘
       │
       │ 验证通过
       ├──────────────────────┐
       │                      │
       │ 验证失败              ▼
       │              ┌────────────────┐
       │              │ 返回401错误     │
       │              │ "Token无效或过期"│
       │              └────────────────┘
       ▼
┌─────────────────────────┐
│ 处理业务请求            │
└─────────────────────────┘

用户登出:
┌─────────────────────────┐
│ 用户主动登出            │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ Token加入黑名单         │
│ Key:                    │
│ login:token:blacklist:{token}│
│ TTL: 24小时             │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 清除用户在线状态        │
│ Key: login:online:{userId}│
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 返回登出成功            │
└─────────────────────────┘
```

## 4. 数据同步流程

### 4.1 Canal实时数据同步

```
┌─────────────────────────┐
│ MySQL数据变更           │
│ - INSERT                │
│ - UPDATE                │
│ - DELETE                │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ MySQL Binlog写入        │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ Canal Server监听Binlog  │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ Canal Client获取数据    │
│ - 批量获取(batch=1000)  │
│ - 超时时间10秒          │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 解析Binlog数据          │
│ - 提取操作类型          │
│ - 提取变更数据          │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 过滤同步表              │
│ - 仅同步sys_user表      │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 构建ES同步消息          │
│ - operationType         │
│ - tableName             │
│ - id                    │
│ - data                  │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 同步到Elasticsearch     │
└──────┬──────────────────┘
       │
       │ 同步成功
       ├──────────────────────┐
       │                      │
       │ 同步失败              ▼
       │              ┌────────────────┐
       │              │ ACK确认         │
       │              │ 继续下一批      │
       │              └────────────────┘
       ▼
┌─────────────────────────┐
│ 发送到RabbitMQ重试队列  │
│ Queue: es.sync.queue    │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 消费者异步重试          │
│ - 最多重试3次           │
│ - 重试间隔递增          │
└──────┬──────────────────┘
       │
       │ 重试成功
       ├──────────────────────┐
       │                      │
       │ 重试失败              ▼
       │              ┌────────────────┐
       │              │ 确认消息        │
       │              └────────────────┘
       ▼
┌─────────────────────────┐
│ 记录失败日志            │
│ 人工介入处理            │
└─────────────────────────┘
```

## 5. 角色权限控制流程

### 5.1 获取用户菜单

```
┌─────────────────────────┐
│ 用户登录                │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 获取用户角色            │
│ role: ADMIN/USER/...    │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 根据角色标识查询角色ID  │
│ SELECT id FROM sys_role │
│ WHERE flag = ?          │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 查询角色的菜单权限      │
│ SELECT menu_id          │
│ FROM sys_role_menu      │
│ WHERE role_id = ?       │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 获取所有菜单(树形结构)  │
│ SELECT * FROM sys_menu  │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 筛选角色可访问的菜单    │
│ - 遍历所有菜单          │
│ - 保留menuIds包含的菜单 │
│ - 过滤子菜单            │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 返回角色菜单列表        │
│ - 树形结构              │
│ - 包含父菜单和子菜单    │
└─────────────────────────┘
```

### 5.2 分配角色菜单权限

```
┌─────────────────────────┐
│ 管理员选择角色          │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 管理员选择菜单权限      │
│ menuIds: [1, 2, 3, ...]│
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 删除原有权限            │
│ DELETE FROM sys_role_menu│
│ WHERE role_id = ?       │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 批量插入新权限          │
│ INSERT INTO sys_role_menu│
│ (role_id, menu_id)      │
│ VALUES (?, ?)           │
└──────┬──────────────────┘
       │
       ▼
┌─────────────────────────┐
│ 返回分配成功            │
└─────────────────────────┘
```
